Principais Formatações

Negrito e Destaque

Nesta frase temos um termo em negrito. Para isto basta usar a tag (não semántica) <b>.

Já aqui temos um termo em destaque. Aqui usamos a tag (semántica) <strong>.

Itálico/Ênfase

Nesta frase temos um termo em itálico. Usando a tag (não semántica) <i>.

E aqui temos um termo com uma ênfase. Para isto usa-se a tag (semántica) <EM>.

Texto Marcado

Também é possível marcar um termo, usando a tag (semántica) <mark>.

A cor do marcador pode ser definida como uma só para facilitar o processo. Para isso é necessário iserir a tag <style> no <head>.

Outro exemplo da marcação personalizada.

Texto Pequeno

Também é possível deixar o texto pequeno, basta usar a tag (semántica) <small>.

Texto Deletado

Para dizer que um termo deve ser ignorado, basta usar a tag (semántica) <del>.

Texto Inserido

Podemos marcar um trecho como inserido, basta usar a tag (semántica) <ins>.

Também tem o sublinhado. A tag (não semántica) usada é <u>.

Sobrescrição de Texto

Para elevar valores, por exemplo, 32 ou coisas do tipo, usa-se a tag (semántica) <sup>.

E para o iverso, por exemplo, H2O, usa-se a tag (semántica) <sub>.
