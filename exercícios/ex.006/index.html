Usa-se a tag <code> para representar as letras do computador por exemplo, print('Hello, wolrd!').

Também existe a tag <pre> ela vai respeitar a formatação dentro dela, por exemplo: 

            
idade = int(input("Insira a sua idade: "))
if idade >= 18:
    print('Acesso liberado!')
else:
    print('Acesso negado!')
